# 🔑 MERN Authentication App

A full-stack authentication system built with the **MERN stack** (MongoDB, Express, React, Node.js).  
It includes secure user registration, login, JWT-based authentication, and protected routes.

---

## 🚀 Features
- User Signup & Login  
- Password Hashing with **bcryptjs**  
- JWT Authentication  
- Protected Routes (Frontend + Backend)  
- MongoDB Database Integration  
- React Frontend with API Integration  
- Session Persistence  

---

## 🛠 Tech Stack
**Frontend:** React, Axios, React Router  
**Backend:** Node.js, Express.js, MongoDB, Mongoose, bcryptjs, jsonwebtoken

## ⚙️ Installation & Setup

### 1. Clone Repository
```bash
git clone https://github.com/your-username/mern-auth-app.git
cd mern-auth-app
```

### 2.Backend
```bash
cd backend
npm install
```
### .env(Backend)
```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
```
npm start
```
### Frontend
```
cd frontend
npm install
npm start
```
